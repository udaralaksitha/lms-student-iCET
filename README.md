# Student Management System (LMS)

A simple, browser-based Student Management System built using **HTML, CSS, and JavaScript**. This project demonstrates basic student record management without requiring a backend or database server.

## 🚀 Features

- **Add Students** — Add new student records.
- **Update Students** — Edit existing student information using a student ID.
- **Delete Students** — Remove student records with confirmation.
- **View Student Records** — Display student details in a table.
- **Duplicate ID Prevention** — Prevent adding students with an existing ID.
- **Local Storage** — Save student records in the browser so they remain available after refreshing the page.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 💻 Getting Started

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Open the Project

Navigate to the project folder:

```bash
cd student-management-system
```

### 3. Run the Application

Open `index.html` in your web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension.

## 📖 How It Works

1. Enter student information in the Add Student form.
2. Add the student to the records table.
3. Use the student ID to find and update an existing record.
4. Delete a student record when necessary.
5. Student records are stored in the browser's Local Storage.

## ⚠️ Limitations

- This is a frontend-only demonstration project.
- No backend server or database is used.
- Records are stored locally in the current browser.
- Data is not automatically shared between different browsers or devices.
- Clearing browser storage may remove saved records.
